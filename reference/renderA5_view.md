# Shiny render function for a5_view

Shiny render function for a5_view

## Usage

``` r
renderA5_view(expr, env = parent.frame(), quoted = FALSE)
```

## Arguments

- expr:

  An expression that returns an a5_view widget.

- env:

  The environment in which to evaluate `expr`.

- quoted:

  Is `expr` a quoted expression?
